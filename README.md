# ⚔️ Neon Arena

A simple browser-based shooting game developed as a **Web Technology assignment**.

## 📌 Project Description

**Neon Arena** is an interactive arena battle game where the player moves around the arena, aims at enemies, and shoots them. Enemies appear in waves, and the difficulty increases as the player progresses.

The project demonstrates the use of **HTML, CSS, and JavaScript** to create an interactive web application.

## 🛠️ Technologies Used

* **HTML5** – Structure of the game
* **CSS3** – Styling, layout, animations, and user interface
* **JavaScript** – Game logic, controls, enemies, shooting, scoring, and interactions
* **HTML5 Canvas** – Game graphics and animations

## 🎮 Features

* Player movement using **WASD / Arrow Keys**
* Mouse-based aiming
* Shooting using **Left Mouse Button**
* Dash ability using **Space**
* Multiple enemy types
* Wave-based gameplay
* Boss enemies
* Health and shield system
* Weapon upgrades
* Coins and scoring system
* Health and shield pickups
* Pause and resume functionality
* Game-over and restart system
* High-score tracking
* Particle effects and screen shake
* Responsive game interface

## 🕹️ Controls

| Control       | Action                  |
| ------------- | ----------------------- |
| W / A / S / D | Move player             |
| Arrow Keys    | Move player             |
| Mouse         | Aim                     |
| Left Click    | Shoot                   |
| Space         | Dash                    |
| P             | Pause / Resume          |
| ESC           | Pause                   |
| R             | Restart after Game Over |

## 📂 Project Structure

```text
NeonArena/
│
├── index.html

├── game.js
└── README.md
```

### `index.html`

Contains the main structure of the game, buttons, HUD, and canvas.

### `style.css`

Contains the styling and visual design of the game interface.

### `game.js`

Contains the complete game logic including player movement, shooting, enemies, waves, scoring, collisions, power-ups, and game states.

## ▶️ How to Run

1. Download or clone the project.
2. Open the project folder in **Visual Studio Code**.
3. Open `index.html`.
4. Run it using **Live Server**.
5. Click **Enter Arena** to start the game.

## 🎯 Objective

The objective of the game is to survive as many enemy waves as possible, defeat enemies, collect coins and power-ups, and achieve a high score.
